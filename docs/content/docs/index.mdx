---
title: Overview
description: There are three ways to use Ocean of Jobs
---

- Browse the platform via a minimalistic and simple web UI.
- Query JSON job data via a REST API
- Use the MCP server with your AI agents.
- Apply to jobs with the browser extension.

<Cards>
  <Card title="MCP server" href="/mcp">
    Connect Claude, ChatGPT or any MCP client and let your agents make the hard work for you.
  </Card>
  <Card title="Browser extension" href="/extension">
    Fill in and send job applications from the board, from your AI agent, or on any company's career page.
  </Card>
  <Card title="REST API" href="/api">
    If you prefer to come up with your own solution you can use the free JSON API. Jobs, companies and market data are all included.
  </Card>
</Cards>
