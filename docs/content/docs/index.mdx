---
title: Overview
description: There are four ways to use Ocean of Jobs.
---

- Browse and search jobs on the website.
- Query JSON job data through the REST API.
- Use the MCP server with your AI agents.
- Apply to jobs with the browser extension.

<Cards>
  <Card title="MCP server" href="/mcp">
    Search jobs, read descriptions and look up companies from Claude, ChatGPT or any MCP client.
  </Card>
  <Card title="Browser extension" href="/extension">
    Fill in and send job applications from the board, from your AI agent, or on any company's career page.
  </Card>
  <Card title="REST API" href="/api">
    A free JSON API for jobs, companies and market data. No key needed.
  </Card>
</Cards>
