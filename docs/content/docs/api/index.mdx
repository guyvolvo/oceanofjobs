title: REST API

---

The base URL is `https://oceanofjobs.com/api`. Public routes need no key. Routes under `/api/me` work on your own account and need a sign-in token.

Fetch the 10 newest open jobs in the United States:

```bash
curl "https://oceanofjobs.com/api/jobs?country=US&limit=10"
```

Every endpoint is listed in the reference, with a "try it" panel that calls the live API from your browser. The same schema is at [/api/openapi.json](https://oceanofjobs.com/api/openapi.json) for code generators.

## Rate limits and caching

- 20 requests a second across all users, with bursts up to 40. Over that you get HTTP 429.
- To export everything, page through `/api/jobs?limit=500` one request at a time, not in parallel.
- Most GET routes are cached for 60 seconds in the browser and 180 at the edge. `/api/pipeline-status` and `/api/geo` are never cached.
- GET and OPTIONS are allowed from any origin.
- Errors are JSON with an `error` key.
