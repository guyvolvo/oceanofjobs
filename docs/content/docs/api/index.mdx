title: REST API

---

Base URL: `https://oceanofjobs.com/api`

For example, to fetch the 10 newest open jobs in the United States:

```bash
curl "https://oceanofjobs.com/api/jobs?country=US&limit=10"
```

Endpoints under `/api/me` are different: they access your own account and require a sign-in token.

## API reference

The [API reference](/api/reference/jobs/get-jobs) documents each endpoint and includes a panel for trying requests against the live API directly in your browser.

For code generation and client integrations, you can also use the [OpenAPI specification](https://oceanofjobs.com/api/openapi.json).

## Rate limits and caching

- Rate limit: 20 requests per second across all users, with bursts of up to 40. Exceeding the limit returns HTTP `429`.
- Bulk exports: To retrieve a large number of jobs, paginate through `/api/jobs?limit=500` sequentially rather than sending parallel requests.
- Caching: Most GET endpoints are cached for 60 seconds in the browser and 180 seconds at the edge. `/api/pipeline-status` and `/api/geo` are not cached.
- Cross-origin requests: GET and OPTIONS requests are allowed from any origin.
- Errors: Error responses return JSON with an `error` field.
